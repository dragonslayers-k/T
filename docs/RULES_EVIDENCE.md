# 규칙 근거 및 미확정 사항

## 확인한 Manual.zip 원문
- soulcost.htm: 무속성 유닛 유지 비용은 매 준비턴 지불하며, 지불 불능분만큼 덱 카드 파괴. 소환 시 무속성 요구량은 어떤 속성 소울로든 지불 가능.
- gamerule.htm: 준비 단계에서 공격자 핸드 6장 보충, 덱에서 보충 불가 시 패배(양측 동시 불가면 공격자 패), 지형 LP/최대 10장, 지형 소울만큼 유닛 필드 배치 가능. 직접 공격은 유닛의 유색+무속성 소울 수만큼 덱 파괴.
- ready.htm: 유닛의 유색 소울은 동일 속성으로 지불하고, 무속성 구슬은 모든 속성 소울로 지불 가능. 아이템은 유닛 능력에 따른 장착 조건이 있음.
- gamescreen.htm: LP는 매턴 1씩 누적, reshuffle 옵션/제한 내용 존재.
- specialability.htm: 특수공격기술별 정의를 각각 구현해야 하며 일반화/대체 금지.

## 주의: 원문 간 충돌
gamerule.htm는 지형 설치 수량을 LP 수만큼 가능하다고 기술하지만 ready.htm의 단계별 설명은 지형 1턴 1장이라고 설명한다. 이 프로젝트는 두 문장을 확정적으로 하나로 합치지 않고, 지형 LP 지불과 턴당 설치 횟수 제한을 서로 다른 규칙으로 둔다. 설치 횟수 정책은 별도 검증 항목이다.

## 현재 구현 범위
초기 순수 함수는 소울 지불의 원자성, 명시적 LP 0 보존, LP 미상 거부, 무속성 유지비 부족 계산만 다룬다. 이는 전체 전투/턴 엔진의 완성 의미가 아니다.
