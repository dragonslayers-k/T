# 2026-11-04 외부 참고자료 대조 결과

- 기준: 불변 `fm1-carddb-29`
- 입력: #460 의미 검토 대기 54행 / 54개 카드 ID
- 외부 자료는 원문 카드 데이터와 공식 매뉴얼의 보조 자료다. 커뮤니티 자료만으로 실행 규칙을 만들지 않는다.
- 나무위키 문서 검색 색인 및 관련 종족·소속 문서에서 카드 유형, 유닛 AP/DP/HP, 아이템 장착, 인챈트 지속 슬롯, 종족·소속 용어를 확인했다.
- Neginote 개인 가이드에서 카드 종류/등급, 지형 LP·유소울/무소울, 유닛 레벨/PT/코인/능력/기술/종족·소속, 마법의 공격·방어 턴 및 유지턴을 확인했다.
- Naver 개인 원작 가이드 URL은 접근 차단으로 본문을 확보하지 못했다. 출처 등록만 하고 본문 내용을 추정하지 않았다.

## 카드별 분류
- 23 디스인첸트 참조: 카드 TextExtra의 공통 정의를 참조 후보로 구조화. 엔진 검증 미완료.
- 7 지형 카운터: TextBase/TextExtra의 마레마/아레아 이름 불일치 보존.
- 8 카드 목록: 이름을 카드 ID로 정확 매칭하고 장착 적격성 확인 대기.
- 8 에카마엘 유닛: 랜덤 풀·랭크 포함·이벤트 등급 제외·홀짝 보너스 후보를 원문 기준 구조화.
- 나머지 8: 조건/상태/주석/분기/실패 조건/변형/불완전 문구로 분리.

모든 행은 `non_executable`이다. DB30 미발행, main 미병합.


## 추가 교차 대조 — 나무위키 내부 링크, 첨부 캡처 및 2017 커뮤니티 기술 목록

- 나무위키 본문에서 속성, 종족·소속, 8개 속성별 카드 색인 및 개별 카드 문서 링크를 확인했다. 선택한 하위 문서와 카드 페이지를 따라갔으나 이 조회에서는 다수 URL이 cache miss로 본문 확보에 실패했다. 링크 목록과 접근 상태는 `fm1-reference-source-registry-2026-11-04.json`의 `linked_page_followups`에 보존한다.
- 나무위키 본문 자체에서 확인한 다섯 카드 유형, 지형 최대 10장/소울 생성, 유닛 AP·DP·HP 및 장비·마법·야수·만능 능력, 아이템 장착 제한, 인챈트 지속 슬롯 설명만 일반 게임 구조의 보조 맥락으로 사용한다.
- 추가 교차자료: 2017-01-30 인벤 커뮤니티 기술 목록(https://www.inven.co.kr/board/hs/3509/1426815). 코스튬체인지 지정 아이템 7개 명칭과 랜덤 장착 설명이 DB29 TextExtra와 일치한다. 다만 대상의 '아이템 미장착' 조건은 커뮤니티 게시글에서 빠져 있으므로 DB29 TextExtra의 조건을 유지한다. 에카마엘 종족 및 지형 수(최대 5)를 참조하는 별도 기술 사례도 확인되나 소환 풀·홀짝 보너스를 검증하지는 않는다.
- 이 커뮤니티 자료는 기술명·목록의 보조 교차참조일 뿐 실행 규칙의 단독 근거가 아니다.
- 사용자가 제공한 Naver 원작 가이드 캡처는 65×1536px로 축소되어 글자를 안정적으로 판독할 수 없었다. 삽입된 게임 화면이 보인다는 사실 외에 규칙/수치 추출은 하지 않았다.
- 54행 전부 `non_executable` 유지. 지정 아이템의 exact card ID·중복 카드명·유닛 능력별 장착 적격성과 에카마엘 풀 예외는 여전히 DB29 원본 데이터/추가 원문 및 엔진 대조가 필요하다.
