# 유닛 특수기술 후보 분류 기준

## 목적 및 신뢰 수준
유닛의 `Skill1`/`Skill2` 또는 사이트의 기술명은 원문 분류값이다. 이 문서는 FM1 기술의 검증 및 구현 작업을 묶기 위한 후보 분류로, 아래 그룹이 게임 내 효과를 모두 설명하거나 확정했다는 뜻은 아니다. 기술 이름이 복합된 값은 복수 기술, 고유 기술, 또는 별도 기술일 수 있으므로 자동 분해 후 실행하지 않는다.

## 구현용 의미 스키마
각 개별 기술은 다음 항목을 채운 뒤 엔진에 연결한다.
- `skill_key`: 안정적인 키. 원문 이름과 별도
- `source_skill_name`: 사이트/원본의 기술명 그대로
- `trigger`: 공격 선언, 공격시, 방어시, 피해 계산, 턴 시작/종료 등
- `actor` / `target`: 소유자와 대상 범위
- `condition_ast`: 레벨, AP/DP/HP, 종족/속성/소속, 필드 상태 등의 조건
- `operation_ast`: 능력치 수정, 피해, 회복, 상태 부여/제거, 공격 횟수, 장비 변경 등
- `duration` / `stacking` / `remove_condition`: 지속, 중첩, 해제
- `resolution_order`: 증거가 있는 경우에만 지정
- `evidence_refs` / `test_case_ids` / `verification_status`: 근거와 검증 추적

## 상태 관리
- `extracted_unverified`: 원문만 확보
- `pattern_candidate`: 이름/문구 후보로 분류
- `manual_mapped`: 매뉴얼 정의와 대응, 개별 사례 검증 전
- `semantics_verified`: 원문·매뉴얼·실제 규칙 근거 연결
- `engine_implemented`: 코드 구현
- `test_verified`: 대표·경계·상호작용 테스트 통과

단계 승격은 증거와 테스트를 요구한다. 기술 이름만 일치하거나 문자열 포함으로 상위 상태를 자동 부여하지 않는다.
