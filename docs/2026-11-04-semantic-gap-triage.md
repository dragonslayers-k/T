비용 쪽은 **미해석 비용 0건**이다. 831건은 모두 원본 비용 문자열이 알려진 토큰으로 파싱됐고, 52건은 하이브리드 색상 토큰의 실제 지불 규칙, 779건은 NCS/BONUS 특수 토큰의 실제 지불 규칙을 별도로 검토하는 상태다. 이를 "비용 미반영" 또는 "파싱 실패"로 취급하면 안 된다. 원본 값과 토큰별 증거는 유지한다.

기술 enum 미매핑 0건은 기술 의미가 전부 검증됐다는 뜻이 아니다. 감사 시점의 917개 기술 enum 중 884개는 카드 원문/기술 설명 근거가 연결됐고, 33개는 이름 기반 저신뢰였다. 커뮤니티 자료와 대조해 9개를 추가 연결한 뒤에도 24개는 이름 기반 저신뢰로 남았다. 이미지 OCR은 24개 중 9개 기술명 존재를 후보 확인했지만, OCR은 기술 효과 설명의 증거가 아니므로 이를 의미 검증 완료로 승격하지 않는다. 27개 매뉴얼 기본 기술도 매뉴얼 정의 검증과 엔진 동작 검증을 구분하며, 엔진 회귀 검증 전 상태는 `pending_engine_test`로 유지한다.

## 이 감사 이후 PR #9에서 반영한 보완

1. 텍스트형 소울 비용의 영문 별칭을 대소문자 무시로 파싱.
2. 숫자형 소울 토큰의 공백/쉼표/세미콜론/더하기 기호 구분자를 제거한 뒤 4자리 토큰 경계로 파싱. 다른 문자는 임의 제거하지 않고 미해결로 유지.
3. 하이브리드와 특수 소울 검토가 한 카드에 함께 있을 때 두 상태가 모두 드러나도록 갭 리포트 상태를 분리.

5. 효과 파서가 에카마엘 상태의 조건 대상 메모, 에피소드 한정 카드 안내, 장식 표식이 붙은 유닛 목록 제목을 비효과/참조로 분류하도록 보완.
6. 방어변환 문구의 DP 양수/음수 기호 전환을 비실행 연산 후보로 구조화.
