## 이 감사 이후 PR #9에서 반영한 보완

1. 텍스트형 소울 비용의 영문 별칭을 대소문자 무시로 파싱.
2. 숫자형 소울 토큰의 공백/쉼표/세미콜론/더하기 기호 구분자를 제거한 뒤 4자리 토큰 경계로 파싱. 다른 문자는 임의 제거하지 않고 미해결로 유지.
3. 하이브리드와 특수 소울 검토가 한 카드에 함께 있을 때 두 상태가 모두 드러나도록 갭 리포트 상태를 분리.
4. 카드 기술 설명에서 추출한 효과 연산 후보에 `executable=false`를 명시. 원문 근거가 있어도 엔진 규칙 테스트 전 자동 실행되는 일을 방지.
5. 효과 파서가 에카마엘 상태의 조건 대상 메모, 에피소드 한정 카드 안내, 장식 표식이 붙은 유닛 목록 제목을 비효과/참조로 분류하도록 보완.
6. 방어변환 문구의 DP 양수/음수 기호 전환을 비실행 연산 후보로 구조화.
