- 기준일: 2026-11-05

- 원문 근거: 각 카드의 DB29 TextExtra / fmlunatic detail URL
- 보조 자료: Inven 2017 특수기술 글 (커뮤니티 자료, 비실행 근거)

## 1. 집계 정정

기존 분류 `named_summon_unit_profile_reference` 8행은 에카마엘 8종을 의미하지 않았습니다. 카드별 원문을 다시 확인한 결과:
- 에카마엘 소환 프로필: **7장**
- 별도 동적 소환 공식: `모래의형상화` 1장
- 별도 조건부 소환 프로필: `추억` 1장 (이서리얼 프로필)

서로 다른 세 소환 모델을 하나의 Ecaemael 풀로 합치지 않습니다.

### 원문에서 구조화한 후보 풀
- 1~3 챕터 유닛

### 에카마엘 지형 수 효과
- 기준: 아군 백필드 에카마엘 지형 수
- 홀수: AP +1
- 짝수: HP +1
- 상태 표기: 하급에카마엘상태

Inven 2017 글은 에카마엘 종족·지형 관련 효과와 지형 수 최대 5를 언급합니다. 이는 커뮤니티의 보조 자료이므로 최대 5를 엔진 하드캡으로 확정하거나 후보 풀을 확정하는 근거로 사용하지 않습니다. 카드 원문에는 일부 제외 카드가 있다는 점만 기록되어 있어 목록은 미확인입니다.

### 엔진 검증 대기
후보 카드 ID 전체, 제외 카드 목록, 등급 enum, 중복/랜덤 가중치, 지형 수 0의 처리, 5 초과 가능 여부, 능력치 갱신 타이밍은 미확인입니다. 테스트 전까지 모두 `pending/non_executable`입니다.

## 3. 별도 유형: 모래의형상화

- 카드 ID: `9010731883`
- 종류: 마법
- 원문 TextBase: 아군 백필드 대지지형 1 파괴 후 속박상태가 2턴 부여된 모래형상 유닛 1을 아군 필드 다음 위치에 소환. [이 건조한 모래에도 한번 쓸 수 있을 만큼은 생명의 기운이 남아 있지.]
- 원문 TextExtra: ★ 속박 상태 : 매턴 소울코스트시에 상대 필드 맨뒤로 이동.<br>★ 모래형상 유닛(야수, 골렘, 돌진공격).<br>* 소환유소울 : 턴의 일의자리수.<br>* 소환무소울 : 턴의 십의자리수.<br>* AP : 소각장 유닛수.<br>* DP : 핸드 유닛수.<br>* HP : 백필드 지형수.<br>▶ 해당 소환 유닛의 최대레벨은 10레벨입니다.

### 소환 조건 및 소환 유닛
- 자신의 백필드 대지 지형 1장 파괴 후 모래형상 유닛 1장을 필드 다음 위치에 소환
- 속박 상태 2턴 부여
- 유닛 분류: 야수, 골렘
- 기술: 돌진공격
- 유소울: 턴의 일의자리 수
- 무소울: 턴의 십의자리 수
- AP: 소각장 유닛 수
- DP: 핸드 유닛 수
- HP: 백필드 지형 수
- 최대 레벨: 10

위 산식은 카드별 원문에서 전사한 구조이지만, 턴 번호 기준과 스냅샷 타이밍은 검증하지 않았습니다. 속박 상태의 이동은 매턴 소울코스트 시 상대 필드 맨 뒤로 이동한다고 설명합니다. 소환 실패 조건/빈 슬롯 처리도 별도 확인이 필요합니다.

## 4. 세 모델 분리 규칙

1. 에카마엘: 카드 풀 필터 + 에카마엘 지형 수 홀짝 능력치 변화
2. 모래의형상화: 턴 자릿수 소울 비용 + 소각장/핸드/백필드 카운트 능력치 산식 + 2턴 속박
3. 추억: 마법학교 유닛 및 지형 수 기반 이서리얼의 조건부 능력치·코인 산식

세 유형은 같은 '소환'이라는 말만으로 공통 처리기로 통합하지 않습니다. 모든 원문을 보존하고 각각의 조건·비용·수식·상태·실패 분기를 독립 검증합니다.
