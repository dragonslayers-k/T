# DB29 RequireSoul 831장 레일 표식 전수 대조 — 3차 결과

## 실행 방식
GitHub Actions workflow `.github/workflows/require-soul-rail-audit.yml`가 DB29 이미지 증거를 내려받아 카드별 레일 표식을 판독했다. 기준 이미지 증거는 기존 Actions run `42357466809`의 `fm1-soul-cost-image-evidence-809` artifact이며, DB29 릴리스 및 카드 원본 데이터는 수정하지 않았다.

- 1차 실행: run `42365287848` — 최신 프레임 템플릿만 적용한 예비 판독
- 2차 실행: run `42365553083` — 구형 프레임 템플릿 추가 후 전수 재판독
- 최종 artifact: `db29-require-soul-rail-audit-2`

특수 토큰 대상 779장 중 778장이 이미지 표식 개수와 원본 RequireSoul 코드별 수량까지 일치했다. 일치율은 99.87%다. 이 수치는 템플릿이 실제 표식과 일치하고 코드별 개수가 원본 토큰 수량과 같다는 뜻이며, 카드의 모든 시각적 속성 의미가 자동으로 확정됐다는 뜻은 아니다.

- 템플릿 카드: `10020324677`, `13041726794`

### Legacy
- 슬롯 중심 y좌표: 88부터 23px 간격으로 14개 위치(마지막 387)
- 템플릿 카드: `5042721718`, `4061821131`, `7111423264`
- 정확 일치: 185장
- BONUS 표식은 구형 프레임 안에서도 두 가지 글리프가 확인되어 두 템플릿을 함께 사용했다.

각 카드마다 두 프레임 계열을 모두 평가하고, NCS(82)·중립(81)·BONUS(83)의 세 수량이 원본과 모두 일치하는 계열만 EXACT_COUNT_MATCH로 기록했다. 임계값을 넘는 표식은 강제로 분류하지 않았다.

## 유일한 미확정 카드

- 카드 ID: `10091525191`
- 이름: 피어스그렘린
- 원본 RequireSoul: `2102 + 8301`
- 아카이브의 large/small 이미지 크기: 100×142
- 표준 카드 프레임 및 좌측 레일 표식이 이미지에 포함되지 않아 현재 두 템플릿으로는 판독할 수 없다.

이는 원본 토큰 오류로 판정하지 않는다. 원본 사이트의 고해상도 카드 이미지 또는 다른 신뢰 가능한 시각 증거가 확보되면 재검증한다. 확보 전까지 상태는 LOW_RES_OR_NONSTANDARD_IMAGE로 유지한다.
