## 하이브리드 52장 — 이미지 패턴 확인

## BONUS / NCS 779장 — 확인된 구조와 미완료 검증

BONUS 코드 83은 439장, NCS 코드 82는 351장에 포함된다. 혼합 카드 11장은 두 토큰을 모두 갖는다. 이미지 왼쪽 레일에서 NCS 표식, 속성별 구슬, 속이 빈 중립 표식이 구분되어 보여 코드 82 및 코드 81 계열을 시각적으로 분리할 근거를 확인했다.

다만 779장 각각의 표식 개수를 픽셀/위치 기준으로 전수 계수하고 원본 토큰 수량과 대조하는 작업은 아직 완료하지 않았다. 따라서 카드별 CSV에는 해당 카드를 `rail_pattern_identified_individual_count_pending`으로 표시했다. 구조 확인과 카드별 수량 검증을 혼동하지 않는다.

### 수량 예외 후보
- 카드 ID `13041726794` / 라리슈어
- 원본 토큰: `8303` (BONUS 3), `8204` (NCS 4), `8101` (중립 1)
- BONUS 수량이 대다수 `8301`과 다른 유일한 수량 3 사례다.
- 왼쪽 레일의 NCS/중립/BONUS 표식 위치와 개수를 별도 계수해 확정해야 한다. 오류로 단정하지 않고 예외 검증 대상으로 유지한다.
