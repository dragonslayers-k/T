## BONUS / NCS 779장 — 시각 표식과 검증 범위

BONUS 코드 83은 439장, NCS 코드 82는 351장에 포함된다. 혼합 카드 11장은 두 토큰을 모두 갖는다. 일부 카드 템플릿에서는 왼쪽 레일의 `N` 표식이 NCS(82), 속이 빈 원형 표식이 중립(81), 원 안의 숫자 `1` 표식이 BONUS(83)에 대응한다. 속성 토큰은 색상 구슬로 표시된다.

### 개별 이미지로 대조 완료한 사례
- `10020324677` 소울바드: NCS 표식 4개 + 중립 원형 표식 2개 = `8204 + 8102`.
- `10021724688` 본드래곤: 속성 구슬 3개 + 중립 원형 표식 4개 + BONUS 숫자 표식 1개 = `1103 + 8104 + 8301`.
- `13041726794` 라리슈어: NCS 표식 4개 + 중립 원형 표식 1개 + BONUS 숫자 표식 3개 = `8204 + 8101 + 8303`. 따라서 `8303`은 데이터 이상치가 아니라 이미지에서 확인되는 유효한 수량이다.

### 아직 남은 검증
779장 전체에 동일한 고정 좌표/템플릿 판독을 일괄 적용할 수는 없다. 카드 세대별로 왼쪽 레일의 표식 디자인과 배치가 다르며, 초기 자동 계수에서 일부 구형 템플릿의 표식을 색상/빈칸으로 잘못 분류하는 사례가 확인됐다. 그러므로 현재는 위 개별 사례와 공통 표식 구조까지만 확정하고, 779장 전체의 카드별 수량 일치율을 주장하지 않는다.

다음 분석은 카드 템플릿/세대별로 레일 위치를 먼저 분류한 뒤, 각 템플릿 안에서 NCS·중립·BONUS·속성 구슬을 계수해야 한다. 불일치와 저신뢰 카드만 확대 이미지로 검수한다.
