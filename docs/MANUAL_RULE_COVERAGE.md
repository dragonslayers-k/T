# FM1 매뉴얼 기반 특수기술 카탈로그 v1

## 이 문서의 역할

이 저장소의 SQLite는 카드 원본 데이터를 보존하는 기준 DB다. 이 문서는 그 위에 얹는 게임 규칙 카탈로그의 출처와 검증 경계를 정의한다. 카드의 원본 Skill1/Skill2 값은 수정하지 않고, 규칙 ID와 별도 매핑 테이블로 연결한다.

## 자료 우선순위

1. **Manual.zip** — Dropbox `/판마/Manual.zip`, `specialability.htm`, 특수기술목록표. 기존 프로젝트 지침상 원작 규칙의 최우선 자료다.
2. **커뮤니티 후대 기록** — 2017-01-30 인벤 게시물 [이쯤에서 카드특수능력을 마구찍는 판마를보자](https://www.inven.co.kr/board/hs/3509/1426815). 2000년대 매뉴얼에 없는 확장 기술과 후대 규칙 차이를 확인하는 보강 자료다. 공식 규칙으로 취급하지 않는다.
3. **원본 카드 데이터와 카드별 설명** — 개별 카드의 Skill1/Skill2, TextBase/TextExtra, 비용, 수치, URL을 대조한다.
4. **유사 카드/통계 추정** — 원본이나 문서가 없을 때만 별도 추정값을 만든다. 추정은 원본 필드에 덮어쓰지 않는다.

## 매뉴얼에 정의된 27개 기본 공격 규칙

아래 27개는 매뉴얼에 있는 기본 공격 유형 27개(일반공격 포함)다. 설명은 실행 목적의 요약이며 매뉴얼 원문을 복사한 것이 아니다.

| 규칙 ID | 원본 기술명 | 핵심 동작 |
|---|---|---|
| `normal_attack` | 일반공격 | 일반 AP 대 DP 피해 |
| `defense_bypass` | 방어무시 | DP를 무시하고 HP 직접 피해 |
| `fatal_attack` | 치명공격 | 유효한 공격 후 대상 HP를 1로 설정 |
| `piercing_attack` | 관통공격 | AP로 DP를 먼저 깎고 남은 피해를 HP에 전달 |
| `weaken_attack` | 약화공격 | 대상 AP/DP 각각 1 감소 |
| `petrify_attack` | 석화공격 | 대상 AP 0, DP +1 |
| `vampiric_attack` | 흡혈공격 | 실제 HP 피해의 절반을 올림해 회복 |
| `aging_attack` | 노화공격 | 대상 AP -2 |
| `charge_attack` | 돌진공격 | 공격자의 AP와 DP를 함께 공격력에 반영 |
| `beast_tamer` | 야수조련 | 야수 대상 AP 0 |
| `bravery_attack` | 용맹공격 | 대상 레벨이 자신 이상이면 추가 피해 1 |
| `regeneration` | 재생능력 | 공격 시 자신 HP +1 |
| `frenzy_attack` | 광분공격 | 자신 HP를 1로 낮춘 희생량을 피해에 더함 |
| `consecutive_attack` | 연속공격 | AP -1 후 남은 AP를 두 배로 적용 |
| `fear_attack` | 공포공격 | 대상 레벨이 자신 이하이면 추가 피해 1 |
| `charm_attack` | 매료공격 | HP 피해가 0이면 대상 AP 0 |
| `ability_seal` | 봉쇄/기술봉쇄 | 대상 특수 공격 기술을 일반공격으로 전환 |
| `spell_suppression` | 마법봉쇄/주문봉쇄 | 마법 능력 대상 AP 0 |
| `weapon_suppression` | 무기뺏기/무기봉쇄 | 장비 능력 대상 AP 0 |
| `copy_attack` | 복제공격/공격복제 | 대상 AP를 공격자의 공격값으로 사용 |
| `shield_break` | 방패파괴 | DP가 음수가 아닌 대상 DP를 0으로 설정 |
| `curse_attack` | 저주공격 | 대상 AP/DP 각각 2 감소 |
| `defensive_use` | 방어이용 | 공격자 AP에 대상 DP를 더한 값으로 HP 직접 공격 |
| `taunt_attack` | 조롱능력/조롱공격 | 대상 HP를 1로 낮추고 감소분을 대상 AP에 더함 |
| `confusion_attack` | 혼란공격 | 대상 AP와 HP 교환 |
| `stealth_attack` | 은폐공격 | 공격 시 자신 DP +1 |
| `defense_convert` | 방어전환/방어변환 | 대상 DP에 음수 표식 적용 |

## 실제 DB enum과 매뉴얼 기술명 연결

원본 DB의 Skill1 표기는 매뉴얼의 표현과 다르거나 시대에 따라 이름이 바뀐 경우가 있다. 따라서 별칭은 다음과 같이 추적한다.

- `기술봉쇄` → 매뉴얼의 봉쇄공격 기술
- `주문봉쇄` → 매뉴얼의 마법봉쇄 기술
- `무기봉쇄` → 매뉴얼의 무기뺏기 기술
- `공격복제` → 매뉴얼의 복제공격 기술
- `방어변환` → 매뉴얼의 방어전환 기술
- `조롱공격` → 매뉴얼의 조롱능력

이 별칭은 카드 이름만 유사해서 합친 것이 아니라 매뉴얼 정의와 후대 기록을 대조한 규칙 매핑이다. 같은 계열처럼 보이는 `무기제압`, `주문제압`, `강한공포` 등은 기본 규칙에 합치지 않고 별도 후보로 유지한다.

## 매뉴얼과 후대 커뮤니티 자료가 다른 경우

기존 매뉴얼을 기본 규칙으로 유지하고, 2017년 자료는 후대 버전 관찰로 별도 보관한다.

| 규칙 | Manual.zip 기본값 | 2017 커뮤니티 관찰 | 처리 |
|---|---|---|---|
| 야수조련 | 야수 대상 AP 0 | AP와 DP 0 | 기본은 AP만 적용, DP 변경은 버전 후보 |
| 주문봉쇄 | 마법 대상 AP 0 | AP와 DP 0 | 기본은 AP만 적용, DP 변경은 버전 후보 |
| 무기봉쇄 | 장비 대상 AP 0 | AP와 DP 0 | 기본은 AP만 적용, DP 변경은 버전 후보 |
| 공격복제 | 상대 AP를 공격값으로 사용 | DP를 무시한다고 설명 | DP 무시 여부를 별도 확인 대상으로 유지 |
| 방어변환 | DP에 음수 표식 | DP의 양/음 부호를 반전한다고 설명 | 매뉴얼의 음수화가 기본값, 반전 방식은 별도 후보 |

## 후대 자료에서 찾은 확장 기술

2017년 자료에는 `자폭공격`, `강한공포`, `강한치명`, `강한돌진`, `장거리공격`, `기술간파`, `무기제압`, `주문제압`, `일격필살`, `체력복제` 등 다수 기술이 추가로 기록되어 있다. 카탈로그 v1은 그중 41개를 별도 `community_documented_candidate`로 수록한다.

이 후보는 카드별 연결과 데이터 보존은 가능하지만, 자동으로 실행 가능한 게임 규칙이 되지는 않는다. 각각의 카드 효과를 테스트하고 매뉴얼 또는 신뢰 가능한 보강 근거를 대조한 뒤에만 구현 상태를 승격한다.

## SQLite 테이블

- `game_rule_catalog`: 정규 규칙 ID, 간단한 실행 정의, 출처 계층, 신뢰도, 구현 상태, 충돌 기록.
- `card_rule_mappings`: 카드별 Skill1/Skill2 원본 값과 정규 규칙 ID의 연결. 원본 숫자 enum과 원본 이름을 모두 보존.
- `skill_enum_inventory`: 현재 카드에서 실제 사용된 Skill1/Skill2 enum별 카드 수, 매핑 수, 미매핑 수.

`manual_verified`는 매뉴얼에 근거가 있다는 뜻이지 엔진 구현이 끝났다는 뜻은 아니다. `community_documented_candidate`는 후대 커뮤니티 자료의 관찰이라는 뜻이고 기본 실행은 금지한다. `unmapped`는 임의로 다른 규칙에 붙이지 않고 조사 대상으로 남긴다.

## 다음 단계

1. 이 카탈로그를 실제 SQLite에 수록하고 15,350장 전체 Skill1/Skill2를 카드별로 연결한다.
2. 기본 27개에 대해 규칙별 테스트, 예외 테스트, 표식(AP/DP/HP) 테스트를 실행한다.
3. 2017 후보 41개를 개별 카드와 원문 설명, 추가 검색자료로 교차검증한다.
4. 마법/인챈트/아이템/지형의 효과는 카드별 AST로 별도 구조화한다.
5. 출처가 없는 경우에만 추정 실행값을 만들고, 원본 값과 분리해 게임 설정에서 선택 가능하도록 한다.
