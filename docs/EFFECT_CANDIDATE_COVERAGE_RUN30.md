# 카드 효과 후보 전수 분류 현황 — SQLite 감사 Run 30

## 분석 출처와 범위
이 보고서는 GitHub Actions `Card quality audit` Run 30에서 생성된 SQLite의 `card_texts`를 집계한 결과다. 대상은 `card_text`와 `additional_text` 17,407개 원문 행, 텍스트 유형을 포함한 고유 문구 조합 12,146개다. 이 수치는 효과 구현률이나 검증률이 아니다. parser v4에서 원문 성격 후보를 별도로 붙이지만 원본 행은 모두 보존한다. 모든 분류는 다중 레이블 표면 패턴 후보이며, 매뉴얼 규칙과 실행 가능 의미를 자동 확정하지 않는다.

## 해석 및 다음 순서

1. `unclassified_candidate` 1,690행을 빈도와 문장 구조로 추가 세분화한다.
2. `※`/조건 분기와 다중 대상/수량 표현이 많은 마법부터 효과를 절 단위로 분리한다.
3. 유닛 기술은 원문 기술 필드와 카드 본문을 구분하고, 27개 핵심 기술을 각자 별도 명세·테스트 대상으로 둔다.
4. 각 후보에 카드 ID, 상세 URL, 원문 ID, 문구 스팬을 보존한다. 숫자만 추출해 효과 수치로 해석하지 않는다.
5. Manual.zip에 있는 규칙 정의가 확인되기 전에는 `semantics_verified` 또는 `engine_implemented`로 승격하지 않는다.

이 집계는 다음 검증 묶음을 정하기 위한 근거다. 게임 효과 전체가 구현되었다고 주장하는 완료 보고서는 아니다.
