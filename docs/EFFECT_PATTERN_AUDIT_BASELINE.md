# 효과 문구 패턴 감사 — 기준 샘플

## 범위 및 주의
2026-11-03에 생성된 품질 감사 산출물의 SQLite `card_texts`에서 `card_text` 및 `additional_text`를 집계한 표면 패턴 분석이다. 아래 분류는 단어/정규식 후보 그룹일 뿐이며, 게임 효과의 의미 검증·구현 상태를 뜻하지 않는다. 본문 텍스트가 반복되는 카드는 개별 원문 레코드 수로 집계했다.

- 고유 텍스트 조합(텍스트 유형 포함): 12,146
- 원문 텍스트 레코드: 17,407

## 후보 그룹 집계

| 그룹 | 레코드 | 해석 한계 |
|---|---:|---|
| 능력치 문구 (AP/DP/HP) | 7,074 | 값 변경, 비교, 비용 등 서로 다른 맥락이 섞임 |
| 피해/공격 해결 문구 | 2,884 | 직접 공격, DP 무시, 반격, 추가 피해 등이 섞임 |
| 미분류 후보 | 2,552 | 패턴 사전 확장이 필요함 |
| 소환/필드/지형 | 1,591 | 대상과 적용 타이밍은 별도 추출 필요 |
| 상태/제어 | 1,556 | 상태 부여와 상태 조건을 구분해야 함 |
| 자원/소울/LP | 1,388 | 코드·색상·수량 의미 검증과 별개 |

| 타이밍/조건 전용 | 151 | 후보 키워드 기준이며 모든 조건을 포괄하지 않음 |

## 반복 템플릿에서 확인된 예
- 방어무시: ‘상대의 DP를 무시하고 HP를 직접공격한다.’
- 용맹공격: ‘자신보다 높거나 같은 레벨을 공격시 자신의 AP+1.’
- 관통공격: ‘AP1 이상으로 공격시 상대의 DP도 깎는다.’
- 돌진공격: ‘상대를 공격시 자신의 AP에 DP를 더해 공격.’
- 치명공격: ‘AP1 이상으로 공격시 상대의 HP=1.’

이 템플릿들은 검증 후보를 정하는 데 사용한다. 문구에 보이는 숫자/조건을 AST로 변환하거나 실행 규칙으로 승격하기 전에 매뉴얼 근거와 실제 규칙 순서를 확인해야 한다. 다음 우선순위는 미분류 2,552개를 소그룹화하고, 매뉴얼에서 정의가 확인되는 반복 효과부터 근거 링크 및 테스트 케이스를 추가하는 것이다.
