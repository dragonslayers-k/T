# FM1 Card Database Rebuild

목표: `https://fmlunatic.com/cardlist`에 등록된 **15,350장 전체**를 카드 단위로 데이터베이스화한다.

이 저장소는 카드DB 전용 재구축 프로젝트다. 과거 크롤링 결과와 구현은 참고 자료일 뿐, 데이터의 정답이나 스키마의 기준으로 사용하지 않는다.

## 절대 기준
- 목표 카드 수: **15,350장**. 일부 표본 또는 일부 페이지로 완료 판정하지 않는다.
- 모든 카드는 개별 `card_id`와 확인된 개별 원본 URL을 갖는다. 개별 상세 페이지가 없는 경우 목록 URL과 사유를 저장한다.
- 원본 데이터, 정규화 데이터, 검증 결과를 분리한다.
- 카드 이미지와 원본 이미지 URL을 모두 보존한다.
- 미상은 `null`, 명시적 0은 `0`. 추정값을 확정값처럼 기록하지 않는다.
- 발견된 원본 필드는 분류 사전에 동적으로 등록한다. 임의로 버리지 않는다.
- 크롤링 실패/차단/누락은 성공으로 집계하지 않는다.

## 새 구조
- `docs/`: 수집·DB 계약 및 품질 기준
- `scripts/probe.mjs`: 사이트 구조와 실제 네트워크/DOM 탐색
- `scripts/crawl.mjs`: 브라우저 관찰 기반 전체 수집
- `scripts/build_db.py`: 원본 JSONL → SQLite 및 정규화 테이블
- `scripts/audit_db.py`: 15,350장 완전성·URL·이미지·필드 감사
- `.github/workflows/carddb.yml`: 수동 실행형 수집·DB 빌드·감사

## 실행 순서
1. GitHub Actions의 `Card DB pipeline`을 `probe` 모드로 실행해 사이트가 실제로 노출하는 API/DOM 구조를 확인한다.
2. probe 결과를 근거로 사이트 전용 페이지네이션/상세 진입 어댑터를 확정한다.
3. `crawl` 모드로 전체 15,350장을 수집한다.
4. SQLite와 원본 JSONL, 이미지 파일을 생성하고 감사한다.

현재는 사이트가 JavaScript 앱으로 동작한다는 점까지만 확인되었다. 실제 API 경로와 상세 페이지 구조는 probe 결과 전까지 추정하지 않는다.
